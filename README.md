# 🌸 春休み六人旅 行き先ルーレット

春休みに6人で行く旅行の行き先を、25府県の中から**完全ランダム**で決めるルーレットです。
ビルド不要の静的サイトなので、GitHub Pages にそのまま置くだけで動きます。

## できること

- **ルーレット**：中央の「まわす」か下のボタンで回転。PC は Space / Enter キーでも回せます
- **候補のON/OFF**：県のボタンをタップすると候補から外せます（2つ以上は残ります）。結果画面の「この県を外してもう一回」で、外してすぐ回し直すこともできます
- **抽選の履歴**：結果はブラウザに保存され、リロードしても残ります（最大50件）
- **効果音**：回転中の拍子木の音と、当選時の太鼓＋ファンファーレ。ボタンでON/OFFできます
- **結果のシェア**：スマホでは共有メニュー（LINE など）が開き、PC では結果の文章をコピーします

## 「完全ランダム」のしくみ

1. 当選する県を `crypto.getRandomValues()`（ブラウザの暗号用乱数）で決めます
2. 棄却サンプリングで剰余バイアスを取り除いているので、候補が N 件なら**どの県も確率はちょうど 1/N** です（25件なら各 4.0%）
3. 区画のどこで止まるか、何周回るか、何秒かけて止まるかも乱数で決めます。演出で結果が変わることはありません

## GitHub Pages で公開する

1. GitHub でリポジトリを作成し、このフォルダの中身を push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ローカルで見る

`index.html` をブラウザで開くだけで動きます。サーバーで確認したい場合は：

```bash
python -m http.server 8000
```

## ファイル構成

- `index.html` … ページの構造
- `style.css` … 和風・春のデザイン
- `script.js` … 候補データ、盤面の描画、抽選、演出、保存

候補を変えたいときは `script.js` の先頭にある `PREFS` を編集してください。
